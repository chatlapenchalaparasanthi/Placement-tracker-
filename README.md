# 🎓 Placement Tracker 333

> Live Demo: https://placement-tracker333.onrender.com

A complete Placement Management System for students & TPO to track company drives, applications, interviews & offers.

### 🚀 Features
- Student Dashboard - Applied / Shortlisted / Selected stats
- Company List - Role, CTC, Eligibility, Deadline
- One-Click Apply & Track Status
- Admin Panel - Add companies, View students
- JWT Authentication

### 🛠️ Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Deployed on: Render
